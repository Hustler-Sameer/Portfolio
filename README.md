# Sameer Kurkure — Portfolio v1

Dark, minimal developer portfolio built with React + Redux Toolkit + Vite.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Structure

- `src/App.jsx` — page sections and layout
- `src/styles.css` — responsive visual system
- `src/data/portfolio.js` — technologies and projects
- `src/app/store.js` — Redux store
- `src/features/projects/projectsSlice.js` — project filtering state
- `src/features/ui/uiSlice.js` — mobile navigation state
